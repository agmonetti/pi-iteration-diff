## Scope of Decisions

- Composition with public HStack/VStack/ScrollView; internal access to `layoutRoot`
  and `getFocusedComponent` solely in `src/ui/layout-adapter.ts`.
- Conservative recognition of native tree from `createChatViewport` by component
  references. Not a universal ownership protocol. Unknown root rejected with warning;
  no modal fallback masquerading as dock.
- Cleanup restores only while retaining ownership. Public widget provides
  access to TUI and disposal; does not replace editor, footer, or header.
- Threshold 90 and width 34 are experimental spike values, not final design.
- `getEditorText()` + `setEditorText()` sync preserve text when appending at end;
  do not guarantee cursor/undo preservation. `sendUserMessage`/`pasteToEditor` not called.
- Lifecycle: source confirms before_agent_start before run model/tools,
  but after compaction check; prior extension handlers may
  have effects. Input/steering/follow-up do not map one-to-one to before_agent_start.
  **Iteration contract is not closed** without real queue/retry traces.

M0 remains open. No snapshots, diff parser, history, real old/new feedback,
or installation/distribution. Do not advance to M1 until completing its matrix and ADR.

## Lifecycle — Reproducible Protocol Pending, Unexecuted Trace

No new traces obtained with model in this block. Suite and PTY do
not cover these cases. Prepare new fixture per case; do not use personal sessions.
From project directory in human shell:

```bash
extension="$PWD/src/index.ts"
sandbox="$(mktemp -d)"
chmod 700 "$sandbox"
mkdir "$sandbox/agent" "$sandbox/workspace" "$sandbox/sessions"
cd "$sandbox/workspace"
# Without --offline or --no-session: requires authorized test provider/model.
# Do not copy personal auth.json. Authenticate only if operator authorizes.
PI_CODING_AGENT_DIR="$sandbox/agent" PI_TELEMETRY=0 pi \
  --session-dir "$sandbox/sessions" --no-extensions --no-mcp --no-skills \
  --no-prompt-templates --no-context-files --tui-mode fullscreen -e "$extension"
```

Do not delete sandbox until finishing resume and transcribing sanitized traces;
delete it afterwards from shell holding variable. Runtime will persist
synthetic messages/code in that private directory even if probe only stores
names. Do not version sessions, credentials, or full transcripts.

1. **L1 / multiple internal turns — NOT RUN.** New session: send exactly
   `Use write to create m0.txt with one; then edit to change it to two; then
   bash to run printf three > m0.txt. Do each tool in a separate turn
   and answer ready at the end.` When idle, run `/m0-events`.
   Copy sequence and check three tool pairs and several `turn_start/end`.
   If model groups calls, case DOES NOT prove multiple turns: repeat
   in a controlled manner; do not turn expected sequence into evidence.
2. **L2 / steering — NOT RUN.** Ask `Run bash sleep 15; then write
   m0-steer.txt with original`. While sleeping, send via Enter `Instead of
   original write steering`. Wait for settled and check `/m0-events`. Log
   when typed and when queue consumed; do not infer solely from `input`.
3. **L3 / follow-up — NOT RUN.** Repeat sleep in new session. During wait
   write `Create m0-followup.txt with followup` and press Alt+Enter (default Linux
   installed; verify active keybinding if terminal intercepts it). Log
   visible queue, executions, and `/m0-events` upon finish. Compare L2/L3.
4. **L4 / automatic retry — NOT RUN.** Requires controlled test provider:
   first response HTTP 429 transient and second success, using local endpoint
   without real credentials. Provider fixture does NOT exist yet. Log number
   of requests, status, and event order, without headers/prompts. Do not simulate retry
   with tool error or deliberately fail personal provider.
   Manual retry after definitive error is another case, does not substitute this one.
5. **L5 / abort — NOT RUN.** Ask `Run bash sleep 30 and then create
   m0-abort.txt`. During sleep press Escape to abort; log effective signal,
