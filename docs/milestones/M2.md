# M2 — Real Diff Viewer with Definitive Interface and Inline Explorer

**Status:** Accepted and completed with definitive visual specification approved by user (Stage A) and visual/spatial polish.

## Summary of Definitive Interface Implemented (Stage A + Visual Polish)

1. **Layout and Dynamic Resizing (`src/ui/layout-adapter.ts`):**
   - **45% Target proportion:** Base width calibrated exactly to 45% of terminal (`Math.round(W * 0.45)`), guaranteeing minimum 46 functional columns for Pi's chat/native editor and minimum 34 columns for dock.
   - **Interactive resizing:** Support for dragging vertical separator with mouse (`event.x === 0`) and keyboard shortcuts (`<` / `>` and `Ctrl+Left` / `Ctrl+Right`) in 4-column increments.
   - **Ratio persistence:** Adjusted width preserved when toggling focus or switching iteration, recalculating proportionally upon terminal resize (`resize`).
   - **Intact ownership and cleanup:** No alteration of native root outside diff session; component identity validation and safe restoration with `dock.close()`.

2. **Inline File Explorer with Two-Line Header (`src/ui/diff-panel.ts`):**
   - **Inline with diffs:** Unified presentation without separate viewers.
   - **Two-line header:**
     - **Line 1:** Expansion indicator (`▾`/`▸`), compact status (`A`, `M`, `D`), file name in bold (`bold`), and statistics (`+X / -Y`). Statuses describe observed delta, not Git staging or renames.
     - **Line 2:** Relative path indented 4 spaces in dimmed color (`dim`), with smart middle path truncation (`truncatePath`) under narrow widths.
   - **Independent expansions:** `Enter` or click on either header line toggles solely that file. Multiple files can remain open.
   - **Initial collapse:** Each new iteration starts with all files collapsed.

3. **Compact Gutter and Optimized Hunks (Unified Diff):**
   - **Compact gutter per file type:**
     - Created files (`new_only`): Prioritizes new line numbers in single compact column (4 chars), freeing 5 extra columns for code.
     - Deleted files (`old_only`): Prioritizes old line numbers in single compact column (4 chars), freeing 5 columns.
     - Modified files (`dual`): Preserves both `old` and `new` references when needed, maintaining exact alignment.
   - **Removal of redundant indentations:** Code brought closer to panel inner edge (code start at column 10 in created/deleted files instead of column 15).
   - **Fixed gutter during horizontal scroll:** `h`/`l` or `←`/`→` scroll code while gutter and separator remain stationary, signaling hidden code with `«` indicator without altering alignment.
   - **Discrete hunk headers (`@@ -X,Y +A,B @@`):** In muted tone (`muted`), selectable for transfer.

4. **Two-Line English Header and On-Demand Technical Notices:**
   - **Two-line header (`basis: 3` including Unicode top border `🭽▔`):**
     - **Line 1:** `▏ DIFF · <Scope>` on left and file count aligned right (`N files` or `1 file`).
     - **Line 2:** Net change summary `▏ +added / -removed` using Pi semantic tokens (`toolDiffAdded`, `toolDiffRemoved`, `dim`) or `▏ No changes` in dim if empty.
   - **Conceptual differentiation of exclusions vs. partial captures:** Paths excluded by policy (.git, node_modules, etc.) do not generate misleading warnings like `[omissions]`; their details are kept on demand in compact view (`d`).
   - **Brief status indicators per ADR-003:** `Last iteration`, `Batch Net`, `Unverified`, `Partial`, `Cancelled`, `Failed`, `Unavailable`.
   - **Full English localization:** Titles, compact statuses `A/M/D`, `[stats unavailable]`, footer and empty messages (`No changes observed in this iteration.`).
   - **On-demand details view:** Accessible via keyboard (`d`) or mouse click on title rows (`y === 1 || y === 2`); top border row only focuses dock.
   - **Vertical navigation:** `↑`/`↓` omit secondary path row; file jumps lead to headers and collapsing a file returns cursor to its header.
   - **Adaptable English footer:**
     - No selection (< 50 cols): `Enter: expand · a: append · Esc: editor`
     - Standard (>= 50 cols): `Enter: expand · a: append · ↑↓: navigate · Esc: editor · d: details`
     - With selection (< 55 cols): `N lines selected · a: append`
     - With selection (>= 55 cols): `Sel: <ranges> (N lines) · a: append to editor`
