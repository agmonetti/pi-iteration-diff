- **Package identity**: `name: "pi-iteration-diff"`, `version: "0.1.0"`, `type: "module"`, `main: "src/index.ts"`.
- **Pi manifest**: `"pi": { "extensions": ["./src/index.ts"] }`.
- **Discovery**: `"keywords": ["pi-package"]` for registration and indexing in Pi package gallery.
- **Dependencies**:
  - `dependencies`: no external runtime dependencies. Code uses exclusively standard Node.js modules (`node:fs`, `node:path`, `node:crypto`, `node:child_process`, `node:os`, `node:util`).
  - `peerDependencies`: declares `@earendil-works/pi-coding-agent: "*"` and `@earendil-works/pi-tui: "*"` as host-provided, avoiding duplicated physical copies or registration collisions per official guidelines.
  - `devDependencies`: development, typing, and test tools (`typescript`, `tsx`, `@types/node`, `@earendil-works/*`).
- **Distribution list (`files`)**: restricts packaging exclusively to:
  - `src/`
  - `README.md`
  - `LICENSE`
  - `package.json`
  Excluded from tarball: `tests/`, development documentation (`M*.md`, `PROGRESS.md`, `REQUIREMENTS.md`, `RESEARCH.md`), test scripts, and work artifacts.

## 2. Installation and Discovery (M5.2)

Support for native Pi installation mechanisms verified:

1. **Native Git installation**:
   ```bash
   pi install git:github.com/agmonetti/pi-iteration-diff
   ```
   Pi clones repo into `<agent-dir>/git/...` and runs `npm install --omit=dev --legacy-peer-deps`. Having no external production dependencies, installation is immediate and free of peer conflicts.

2. **Local / project installation**:
   ```bash
   pi install ./path/to/pi-iteration-diff
   pi install ./path/to/pi-iteration-diff -l   # In .pi/settings.json
   ```

3. **Loading without `-e`**:
   Pi discovers entrypoint via `package.json` (`pkg.pi.extensions = ["./src/index.ts"]`). Commands `/diff` and `/diff-settings` registered automatically in interactive session.

4. **Configuration preservation**:
   Global dock persistence (`<agent-dir>/iteration-diff.json`, permissions `0600`) remains decoupled from package lifecycle: not deleted or modified when reinstalling, updating, or uninstalling extension.
